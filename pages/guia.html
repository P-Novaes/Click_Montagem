Guia de Instalação Completo

Passo a passo para colocar o sistema funcionando 100% no localhost com XAMPP, phpMyAdmin e PHP.

Passo 01

Estrutura de Pastas

Crie esta estrutura exata dentro da pasta htdocs do XAMPP:

# Windows: C:\xampp\htdocs\ # Mac/Linux: /Applications/XAMPP/htdocs/ ou /opt/lampp/htdocs/ htdocs/ └── click_montagem/ ├── html/ │ ├── login.html ← sua página de login │ ├── orcamento.html ← formulário de orçamento │ └── propostas.html ← lista de propostas ├── css/ │ ├── shared.css │ ├── login.css │ ├── orcamento.css │ └── propostas.css ├── js/ │ ├── api.js ← NOVO: módulo central da API │ ├── login.js │ ├── orcamento.js │ └── propostas.js ├── php/ │ ├── conexao.php ← inclua em todos os outros │ ├── usuarios.php │ ├── orcamentos.php │ └── propostas.php └── click_montagem.sql ← importe no phpMyAdmin
Passo 02

Importar o Banco de Dados

1

Inicie o XAMPP

Abra o XAMPP Control Panel e clique em Start nos serviços Apache e MySQL. Ambos devem ficar verdes.

2

Abra o phpMyAdmin

Acesse no navegador:

http://localhost/phpmyadmin
3

Importe o SQL

Clique em Importar (menu superior) → Escolher arquivo → selecione click_montagem.sql → clique em Executar.

✓
O banco click_montagem será criado automaticamente com as tabelas usuarios, orcamentos e propostas, mais dados de exemplo.
Passo 03

Ordem Correta dos Scripts nos HTMLs

Inclua api.js antes de qualquer outro JS do projeto:

HTML — antes do </body> 
<!-- login.html, orcamento.html, propostas.html -->

<!-- 1. Módulo central da API (obrigatório primeiro) -->
<script src="../js/api.js"></script>

<!-- 2. Script específico da página -->
<script src="../js/login.js"></script>
<!-- ou: orcamento.js / propostas.js -->
⚠
Atenção nos caminhos — como os HTMLs estão em /html/, o caminho correto para os scripts é ../js/api.js (dois pontos + barra = subir um nível).

Solução de Problemas

Erros Comuns e Correções

❌ "No 'Access-Control-Allow-Origin' header"

Erro de CORS quando o JS tenta chamar o PHP.

✅ Solução: Certifique-se de que conexao.php está sendo incluído em todos os arquivos PHP (o header CORS está nele). E acesse sempre via localhost, nunca abrindo o HTML como arquivo local (file://).

❌ "Falha na conexão com o banco"

PHP não consegue conectar ao MySQL.

✅ Solução: Verifique se o MySQL está Started no XAMPP. Em conexao.php, DB_USER = 'root' e DB_PASS = '' (vazio) são os padrões do XAMPP. Se você definiu senha no MySQL, atualize DB_PASS.

❌ "Rota inválida 404"

O endpoint não foi reconhecido pelo PHP.

✅ Solução: Verifique a URL completa. O parâmetro action= deve existir e ter exatamente o valor esperado (ex: cadastrar, não Cadastrar). Use o console do navegador (F12) para ver a requisição real.

❌ "SyntaxError: Unexpected token < in JSON"

PHP retornou HTML (provavelmente uma página de erro) em vez de JSON.

✅ Solução: Abra a URL do PHP diretamente no navegador para ver o erro completo. Geralmente é um require_once com caminho errado ou erro de sintaxe PHP.

❌ Imagens/CSS não carregam

Caminhos relativos errados no HTML.

✅ Solução: Como os HTMLs ficam em /html/, use ../css/arquivo.css para subir um nível. Nunca use caminhos absolutos como C:\xampp\....

❌ "Este e-mail já está cadastrado"

Tentativa de cadastrar o mesmo e-mail duas vezes.

✅ Normal — o banco tem uma restrição UNIQUE no e-mail. Use um e-mail diferente ou delete o usuário no phpMyAdmin antes de recadastrar.
